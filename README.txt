GitHub User Finder

**Автор:** Александра Карпенко 

Описание

GUI-приложение для поиска пользователей GitHub, просмотра результатов и сохранения избранных пользователей.  
Позволяет:
- Искать пользователей по логину через GitHub API.
- Просматривать результаты поиска в виде списка.
- Добавлять пользователей в избранное и удалять их.
- Сохранять избранное локально в JSON-файл.
- Проверять, что поле поиска не пустое.

Как использовать API

Приложение обращается к публичному REST API GitHub:
- **Endpoint:** `GET https://api.github.com/search/users`
- **Параметры:** `q` – поисковый запрос (логин пользователя), `per_page` – количество результатов (30).
- **Ответ:** JSON с полями `items`, где каждый элемент содержит `login` и `id`.
- **Лимиты:** без аутентификации – до 60 запросов в час. При превышении API вернёт ошибку 403.

В коде используется библиотека `requests`. Запрос выполняется асинхронно (в отдельном потоке), чтобы не блокировать интерфейс.
